NEED TO KNOW?

Quick answers.

Which Windows version do I need?＋

PM-2 is provided as a 64-bit Windows installer. A compatible Windows 10 or Windows 11 PC is recommended.

Why does setup need WebView2?＋

PM-2 uses Microsoft Edge WebView2 to display the game inside its desktop window. The setup bundle checks for the runtime and can install it if needed.

Where can I find newer versions?＋

Come back to this official PM-2 download page. The download button points to the latest published installer release.
